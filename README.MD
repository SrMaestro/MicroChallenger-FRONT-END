# Front-end Iniciante

## DESCRIPTION

Criar um portfólio profissional online que fortaleça a presença digital do desenvolvedor, organizando e apresentando suas informações, habilidades e projetos de forma visual, clara e atrativa.

---

# CBL

**Mentor Driven Challenge:**  
Criar uma interface simples que ajude um usuário na organização de informações com base em informações fornecidas.

**Big Idea:**  
Presença digital.

**Essential Question:**  
Como destacar habilidades técnicas na área de tecnologia?

**Challenge:**  
Organizar projetos de desenvolvimento de forma visual e atrativa.

---

# GOALS

- Compreender o papel do front-end em uma solução digital.
- Criar uma interface simples e funcional.
- Organizar informações de forma clara.
- Exibir um resultado compreensível.
- Explicar como a interface ajuda o usuário.

---

# DURATION

**3 semanas**

---

# GROUPS

**Individual**

---

# DELIVERABLES

- Interface funcional desenvolvida em HTML, CSS e JavaScript básico.
- Repositório no GitHub.
- Navegação simples entre seções.
- HTML semântico.
- Prototipação de baixa e média fidelidade da interface.
- Exibição de um resultado baseado nas entradas.
- Explicação de como a interface apoia a decisão do usuário.

---

# PRESENTATION

N/A.

---

# CONSTRAINTS

- Utilizar HTML, CSS e JavaScript.
- Não utilizar frameworks.
- Não integrar com backend ou banco de dados.
- Priorizar UX.
- A interface deve conter, no mínimo:
  - uma seção de apresentação;
  - uma seção de projetos.
- Deve existir pelo menos uma interação simples.
